# moodrobe

ตู้เสื้อผ้าออนไลน์ส่วนตัว วางแผนช้อปปิ้งรายเดือน จับคู่ชุดล่วงหน้า และเก็บไดอารี่ OOTD

## ฟีเจอร์

- **Wishlist**: ลิสต์ของที่อยากได้ในแต่ละเดือน ใส่รูป ลิงก์ร้าน และราคาได้ มีตั้งงบประจำเดือน ติ๊ก "ซื้อแล้ว" ของจะย้ายเข้าตู้ให้อัตโนมัติ
- **Closet**: เก็บเสื้อผ้าที่มีแยกตามหมวด ตัดพื้นหลังรูปได้ในตัว และบอกว่าแต่ละชิ้นใส่ไปแล้วกี่ครั้ง
- **Styling**: บอร์ดแมทช์ชุด ลากวางเสื้อผ้า ย่อ/ขยาย หมุน ใส่สติกเกอร์ได้ มีปุ่มสุ่มลุค และบันทึกลุคพร้อมวันที่จะใส่
- **Diary**: ปฏิทินบันทึกการแต่งตัวแต่ละวัน ใส่รูปตอนใส่จริงได้ ให้คะแนน 1–10 และมีสรุปลุคที่ได้คะแนนสูงสุดกับชิ้นที่ใส่บ่อยที่สุด

## วิธีใช้งาน

เป็นเว็บไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไร

รันบนเครื่องตัวเอง:

```bash
python3 -m http.server 5178
```

แล้วเปิด http://localhost:5178

### ขึ้นเว็บด้วย GitHub Pages

1. push โฟลเดอร์นี้ขึ้น GitHub
2. ไปที่ **Settings → Pages**
3. เลือก Branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
4. รอสักครู่ จะได้ลิงก์ประมาณ `https://<username>.github.io/moodrobe/`

## ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมดเก็บใน IndexedDB ของเบราว์เซอร์ที่ใช้อยู่เท่านั้น ไม่มีการส่งขึ้นเซิร์ฟเวอร์

- คอมกับมือถือจะเห็นข้อมูลไม่ตรงกัน เพราะเก็บแยกกันคนละเครื่อง
- ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลในแอปจะหายด้วย
- สำรองข้อมูลได้ที่เมนู **⋯ → Back up** จะได้ไฟล์ `.json`
- กู้คืนได้ที่เมนู **⋯ → Restore** ใช้ย้ายข้อมูลข้ามเครื่องได้ด้วย
